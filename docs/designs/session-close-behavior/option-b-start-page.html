行为 SPEC

「开始」页签固定在页签栏最左，无 ×，永远存在；⌘1 直达。空窗口时默认落在它上面
close(tab)激活「开始」页；被关会话进入最近列表顶部并带「刚刚关闭」标记 5 分钟
恢复最近会话单击即重新打开为页签并激活；会话内容从未被销毁（关闭的只是页签视图）
心智模型「页签是会话的窗口，开始页是会话的家」——关闭 = 收起来，不是丢弃
风险多一个常驻页签占位；从「关闭相邻会话」回到开始页可能比相邻激活多一步（可与方案 A 混合：有相邻走相邻，关完落开始页）
