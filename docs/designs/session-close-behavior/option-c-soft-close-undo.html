行为 SPEC

close(tab) 有剩余激活左侧相邻页签 + toast「已关闭 X · 撤销」6s；⇧⌘T 随时反悔
close(最后一个)画布渲染「已关闭」占位卡：关闭对象名称 + 内容保留声明 + 重新打开主按钮——占位卡是「状态说明」，不是幽灵内容
撤销栈关闭记录进 LIFO 栈（上限 10），⇧⌘T 逐个恢复并激活；恢复位置 = 原 index
心智模型「关闭是收进抽屉，不是扔碎纸机」——toast 与占位卡把「可恢复」显式化，消除误关焦虑
风险toast 可能打断心流（可设 6s 自动消失 + 不抢焦点）；撤销栈需要跨 workspace 记录 tab 引用
