增强提示词 · 并排对照

模型选择用 Composer 同一套：引擎子菜单 → 该引擎模型。引擎只显示供应商设置里已启用的 CLI。 增强强度加回来了：它改的是改写策略，不是模型推理力度。三档含义写在右侧说明里，切一下就能看到结果骨架怎么变。

供应商设置 · 已启用

点一下切换启用。未启用的引擎不会出现在模型菜单里。菜单文案跟 Composer ModelSelect 一样用小写 id。

弹窗怎么选模型

  • 触发器是 Composer 的 pill：当前模型名 + chevron。
  • 展开后先是引擎列表（Claude Code / Codex CLI / …），当前引擎带绿点。
  • hover 引擎打开右侧模型列表，点一项同时选定引擎和模型。
  • 增强强度在模型 pill 右侧：轻润色 / 结构化 / 可执行。
