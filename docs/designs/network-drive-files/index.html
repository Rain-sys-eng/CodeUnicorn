把网络盘上的文件夹加成工作区

用户把 RaiDrive / SSHFS 挂出来的目录（例如 E:\ceshi）通过「添加项目」做成工作区。 工作区根就是那个外部文件夹。右侧 Files 在修复前永远「加载失败」，修复后可以浏览、打开。

和「工作区内再挂一个外部文件夹」不是一回事 产品现有能力是：一个工作区 = 一个根目录。没有「在已有工作区里再 mount 第二个外部文件夹」的 UI。 这个原型演示的是用户实际踩到的路径：把外部/网络盘目录当成工作区根。
