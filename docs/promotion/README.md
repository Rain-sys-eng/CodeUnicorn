# mossx 客户端推广文档

本目录承载面向**外部用户与潜在用户**的产品推广材料：能力介绍、场景故事、对比说明。与 `docs/analysis/**`（内部事实分析）分层——推广文档讲「价值与体验」，技术契约仍以 [OpenSpec](../../openspec/specs/README.md) 和代码为准，禁止在推广文案中虚构未 shipped 的能力。

## 写作口径

- 中文为主体，technical terms（CLI / Provider / Shared Session 等）保留 English
- 卖点必须有事实源：能力描述可回溯到 `docs/analysis/**` / `openspec/**` / 代码
- 对比类内容保持诚实：写清适用边界与成本（如「准备上下文」），不做过度承诺
- 截图、演示数据等素材落 `docs/promotion/assets/`
